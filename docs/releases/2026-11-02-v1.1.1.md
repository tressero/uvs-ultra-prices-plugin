# v1.1.1 — prices that survive a sleeping background worker, and www

## Fixes

- **Prices no longer disappear at random.** Chrome stops an idle extension
  service worker after about thirty seconds, and the first message after that
  often fails with "Receiving end does not exist" or "The message port closed
  before a response was received". The extension made exactly one attempt and
  then gave up silently, so a deck page could load with no prices at all and no
  explanation. The quote request now retries three times before giving up.
- **A failure is visible instead of silent.** When a quote really cannot be
  fetched, the deck page shows a short panel with the reason and a "Try again"
  button, deck lists mark the row and allow a retry, and card pages retry once
  rather than leaving dead marks.
- **`www.uvsultra.online` works.** The site answers on both hosts, but the
  manifest only matched the apex domain, so arriving from a bookmark or a search
  result on `www.` produced no prices anywhere. Every content script now matches
  both hosts, and both are declared as host permissions.

## Upgrade note

`www.uvsultra.online` is a new host permission. Chrome may ask existing users to
approve it once after the update; the extension keeps working on the apex domain
either way.
